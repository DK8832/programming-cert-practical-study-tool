# CODE:90 — 프로그래밍기능사 작업형 대비 웹 학습도구

SQL·Python·Java·Linux 개념을 자체 구성 50문제로 점검하는 설치 없는 웹 학습도구입니다. 답안은 현재 브라우저의 `localStorage`에만 저장됩니다.

## 핵심 기능

- SQL 20문제, Python 10문제, Java 10문제, Linux 10문제
- 공식 실기 시간에 맞춘 90분 모의시험 타이머
- 문제별 즉시 채점 연습 모드
- 답안·현재 위치·남은 시간 자동 저장과 이어 풀기
- 전체 채점, 영역별 점수, 오답·미응답 분석
- 오답만 다시 구성하는 약점보정 세트
- 결과 CSV·JSON 저장, 브라우저 인쇄·PDF 출력
- 키보드 포커스, 건너뛰기 링크, 모바일 반응형 화면

## 실행

가장 간단한 방법은 배포 패키지의 `dist/CODE90_standalone.html`을 더블클릭하는 것입니다. 원본 모듈 구조를 실행하려면 이 폴더에서 정적 서버를 실행합니다.

```powershell
python -m http.server 4173
```

그다음 `http://localhost:4173`을 엽니다.

## 자동 테스트

Node.js 22 이상에서 다음 명령을 실행합니다.

```powershell
npm test
```

단일 HTML을 다시 만들려면 다음을 실행합니다.

```powershell
npm run build
```

검증 항목은 문제 수·영역별 개수, 중복 ID, 정답 인덱스, 단답형 정규화, 0점·100점 계산, 타이머 표기, CSV 이스케이프입니다.

## 자료와 범위

- Q-Net 종목 정보에서 프로그래밍기능사 실기가 작업형 1시간 30분임을 확인했습니다.
- 문제는 학습 목적으로 새로 작성했으며 공식 기출문제나 공개문제를 복제하지 않았습니다.
- 저장·출력되는 결과에는 이름, 학번, 계정 같은 개인정보가 포함되지 않습니다.
- 합격을 보장하거나 실제 시험 점수와 동일하다고 주장하지 않습니다.
