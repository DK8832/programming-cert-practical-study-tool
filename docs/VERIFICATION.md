## 수동 확인 체크리스트

- [ ] 90분 모드에서 문제별 채점 버튼이 숨겨지는가

- [ ] 오답만 다시 풀기에서 정답 문제는 제외되는가
- [ ] CSV와 JSON이 내려받아지는가
