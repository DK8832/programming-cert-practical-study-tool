# 프로그래밍기능사 작업형 대비 50문제 웹 학습도구 제작·개선

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 문제 | SQL·Python·Java·Linux 내용을 반복해서 확인하고, 틀린 영역을 바로 다시 공부하기 어려웠다. |

## 01. 문제와 목표

프로그래밍기능사 실기를 준비하면서 SQL·Python·Java·Linux 내용을 여러 문서에서 다시 찾는 과정이 번거로웠다. 모의시험을 마지막에 한 번만 채점하면 어떤 개념을 틀렸는지 바로 확인하기 어렵다는 문제도 있었다. Q-Net 종목 정보에서 실기 검정방법이 작업형 1시간 30분임을 확인하고, 90분 모의시험과 문제별 즉시 채점 연습을 하나의 웹 도구로 만들었다.

문제는 공식 기출문제를 옮기지 않고 학습용으로 직접 새로 구성했다. SQL 20문제, Python 10문제, Java 10문제, Linux 10문제로 총 50문제다.

## 02. 구현 구조

`questions.js`는 문제·선택지·정답·해설을 데이터로 분리한다. `core.mjs`는 정답 판정, 영역별 점수 계산, CSV 변환을 화면 코드와 분리했다. `app.js`는 문제 이동, 타이머, 자동 저장, 결과 화면을 담당한다.

```text
문제 데이터
  → 답안 입력
  → localStorage 자동 저장
  → 문제별 채점 또는 전체 제출
  → 영역별 점수 계산
  → 오답 ID로 약점보정 세트 생성
  → CSV·JSON·인쇄/PDF 결과 출력
```

개인정보 입력란을 만들지 않았고 답안은 서버가 아니라 현재 브라우저에만 저장된다.

## 03. 개선 과정

처음 기획은 전체 문제를 마지막에 한 번 채점하는 40문제 구조였다. 원본 대화를 다시 대조한 결과 최종 요구가 50문제·90분·즉시 채점·이어 풀기까지 확장되어 있음을 확인했다. 따라서 SQL 비중을 20문제로 늘리고 Python·Java·Linux를 각 10문제로 맞췄다.

전체 채점만 있으면 틀린 이유를 즉시 확인하기 어렵기 때문에 `즉시 채점` 모드를 추가했다. 반대로 모의시험 중 해설이 먼저 보이면 실제 연습 효과가 떨어질 수 있어 `90분 모의` 모드에서는 현재 문제 채점 버튼을 숨겼다.

페이지를 닫았을 때 답안이 사라지는 문제는 답안, 현재 번호, 남은 시간, 채점 상태를 `localStorage`에 저장하는 방식으로 해결했다. 최종 결과에서 틀린 문제 ID만 추려 같은 문제를 다시 푸는 약점보정 세트도 추가했다.

## 04. 검증 결과

- 총 문제 수 50개 확인
- SQL 20·Python 10·Java 10·Linux 10개 확인
- 문제 ID 중복 0개
- 선택형 정답 인덱스 범위 검사
- 모든 정답 입력 시 100점, 미응답 시 0점 확인
- 단답형 공백·대소문자 정규화 확인
- 90:00과 00:00 타이머 표기 확인
- 쉼표·따옴표가 있는 문장의 CSV 이스케이프 확인
- 모바일 1열 전환, 키보드 포커스, 건너뛰기 링크 적용

## 05. 한계와 다음 단계

현재 50문제는 학습용 자체 구성 문제이며 실제 시험의 난도와 점수 분포를 대표하지 않는다. 장기간 사용에 따른 성적 향상도 아직 측정하지 않았다. 다음에는 직접 반복 사용하면서 자주 틀리는 문제의 표현을 수정하고, 실제 터미널·코드 실행 결과를 입력하는 실습형 문제를 별도 세트로 확장할 계획이다.

## 06. AI 활용 범위

기존 학습자료와 요구사항을 정리하고 HTML/CSS/JavaScript 코드 및 자동 테스트 초안을 만드는 데 Codex를 활용했다. 공식 시험 시간은 Q-Net에서 다시 확인했고, 문제는 공식 기출문제 복제가 아니라 학습용 자체 구성임을 표시했다. 공개 전에는 사용자가 문제 내용과 실제 실행 화면을 직접 검토해야 하며, 확인하지 않은 성적 향상·합격·사용 기간은 적지 않았다.
