프로그래밍기능사 작업형 대비 50문제 웹 학습도구

SQL·Python·Java·Linux 학습 내용을 한곳에서 반복해서 확인하기 위해 90분 모의시험과 문제별 즉시 채점을 지원하는 웹 학습도구를 제작했다. 설치 없이 실행할 수 있고 답안·현재 위치·남은 시간을 브라우저에 자동 저장하며, 제출 뒤에는 영역별 점수와 오답만 모은 약점보정 세트를 제공한다.

1. 문제와 목표

프로그래밍기능사 실기를 준비하면서 내용을 여러 문서에서 다시 찾는 과정이 번거로웠다. 전체 문제를 마지막에 한 번만 채점하면 틀린 이유를 바로 확인하기 어렵고, 페이지를 닫았을 때 답안과 학습 위치가 사라지는 문제도 있었다. Q-Net 종목 정보에서 실기 검정방법이 작업형 1시간 30분임을 확인하고 90분 모의시험과 즉시 채점 연습을 하나의 도구로 통합했다.

문제는 공식 기출문제를 옮기지 않고 학습용으로 새로 구성했다. SQL 20문제, Python 10문제, Java 10문제, Linux 10문제로 총 50문제다.

2. 주요 기능

  • 90분 모의시험: 해설을 숨기고 마지막에 전체 채점
  • 즉시 채점: 현재 문제에서 정답 여부와 해설 확인
  • 자동 저장·이어 풀기: 답안, 현재 번호, 남은 시간, 채점 상태 복구
  • 영역별 분석: SQL·Python·Java·Linux 점수와 오답·미응답 표시
  • 약점보정: 틀린 문제 ID만 모아 다시 풀기
  • 결과 출력: CSV·JSON 저장과 브라우저 인쇄·PDF
  • 모바일·키보드 지원: 반응형 배치, 건너뛰기 링크, 포커스 표시

3. 화면과 사용 흐름

  1. 90분 모의 또는 즉시 채점 모드를 선택한다.
  2. 문제 번호를 이동하며 답안을 입력한다.
  3. 답안과 현재 위치가 현재 브라우저에 자동 저장된다.
  4. 전체 제출 시 총점과 네 영역의 점수를 계산한다.
  5. 오답만 다시 풀거나 CSV·JSON·인쇄 결과를 저장한다.

5. 개선 과정

처음 확인한 옛 기획은 40문제와 전체 채점 중심이었다. 공유 대화의 최종 요구를 다시 대조해 50문제·90분·즉시 채점·자동 저장·이어 풀기로 확장했다. 모의시험 중 해설을 먼저 보면 연습 효과가 떨어질 수 있어 90분 모드에서는 현재 문제 채점 버튼을 숨겼고, 연습 모드에서만 즉시 해설을 표시했다.

모듈형 index.html은 일부 브라우저에서 더블클릭 실행이 막힐 수 있어 원본 구조는 유지하면서 모든 CSS·문제·로직을 하나로 결합한 CODE90_standalone.html도 만들었다.

6. 실제 검증 결과

  • 전체 문제 50개, SQL 20·Python 10·Java 10·Linux 10개 확인
  • 중복 문제 ID 0개, 선택형 정답 인덱스 범위 오류 0개
  • 모든 정답 입력 시 100점, 전체 미응답 시 0점 확인
  • 단답형 공백·대소문자 정규화 확인
  • 제한 시간 5,400초와 화면 90:00·00:00 표기 확인
  • 쉼표·따옴표가 포함된 문장의 CSV 이스케이프 확인
  • 자동 테스트 4개 중 4개 통과, 로컬 실행 페이지 HTTP 200 확인

7. 핵심 코드 설명

gradeAnswers(questions, answers)
→ 문제별 answered / correct 계산
→ 영역별 total / correct / percent 계산
→ 전체 total / answered / correct / percent 반환

normalizeAnswer는 단답형의 앞뒤 공백, 대소문자, 연속 공백, 마지막 세미콜론을 정리한다. isCorrect는 선택형 정답 인덱스와 단답형 허용 답안을 각각 비교한다. gradeAnswers는 같은 상세 결과 배열을 총점·영역별 점수·오답 목록에 재사용한다. validateQuestionBank는 중복 ID, 필수 필드, 선택지 수, 정답 인덱스를 실행 전에 검사한다. resultToCsv는 쉼표·따옴표·줄바꿈이 있는 문장을 올바르게 감싸 결과 파일이 깨지지 않도록 한다.

8. 개인정보와 저장 방식

이름·학번·계정 입력란을 만들지 않았고 답안은 서버로 전송하지 않는다. 현재 브라우저의 localStorage에는 답안, 현재 문제, 남은 시간, 모드, 채점 상태만 저장한다. 결과 JSON에도 점수·영역별 결과·오답 문제 ID만 포함한다.

9. AI 활용 범위

기존 학습자료와 최종 요구사항을 정리하고 HTML/CSS/JavaScript 코드 및 자동 테스트 초안을 만드는 데 Codex를 활용했다. 공식 시험 시간은 Q-Net으로 재확인했고, 문제는 공식 기출문제 복제가 아니라 학습용 자체 구성임을 표시했다. 확인하지 않은 성적 향상·합격·장기간 사용 효과는 적지 않았다.

10. 한계와 다음 단계

현재 50문제는 학습용 자체 구성 문제이며 실제 시험의 난도와 점수 분포를 대표하지 않는다. 장기간 사용에 따른 성적 향상도 아직 측정하지 않았다. 다음에는 직접 반복 사용하며 자주 틀리는 문제 표현을 교정하고, 실제 터미널·코드 실행 결과를 입력하는 실습형 세트를 별도로 확장할 계획이다.
